--------------------------------------------------------------------------------
CATEGORY 1: CORE TYPING ENGINE & INTELLIGENT TEXT MECHANICS
--------------------------------------------------------------------------------

1. Multi-Lingual Layout Engine:
   - English (US / QWERTY): Standard typing layout jisme har key par secondary symbols mapped hain.
   - Bangla Avro (Phonetic Engine): English me type karo aur real-time Bengali script banegi 
     (jaise "ami" -> "আমি", "kemon" -> "কেমন"). Isme smart candidate prediction aur yuktakshar support hai.
   - Bangla National / Jatiya Layout: Official traditional layout accurate Bangla typing ke liye.
   - Hindi (Devanagari): Swar, vyanjan, matras aur sanyuktakshar ke sath full layout.
   - Layout Switcher: Spacebar ko swipe/hold karke ya dedicated Globe key (🌐) dabakar instant switch hota hai.

2. Auto-Capitalization & Sentence Intelligence:
   - Keyboard open hote hi pehla character automatically Capital (ShiftState.SHIFTED) rehta hai.
   - Sentence terminators (". ", "? ", "! ") ke baad Space ya Enter press hote hi agla word automatically Capital ho jata hai.
   - Shift states: OFF (small letters), SHIFTED (1 letter capital), CAPS_LOCKED (permanent capital).

3. Smart Double-Tap Caps Lock:
   - Single tap: Normal Shift toggle (OFF <-> SHIFTED).
   - Fast double tap (<380ms threshold): Hardware keyboard ki tarah CAPS_LOCKED ho jata hai with active bottom indicator pill.
   - Wapas tap karne par instantly OFF ho jata hai.

4. Punctuation Spacing Auto-Collapse:
   - Suggestion bar se word select karne par naturally ek space add hoti hai ("word ").
   - Agar user space ke turant baad koi punctuation mark dabata hai (., ?, !, ,, ;, :), toh keyboard pichli automatic space ko delete karke naturally "word." bana deta hai (na ki "word .").

5. Double-Space Period:
   - Spacebar ko do baar fast tap karne par automatically ". " commit ho jata hai aur agla letter capital hone ke liye ready rehta hai.

6. Universal Hold-to-Repeat Backspace Engine:
   - Har ek screen (Letters keyboard, Emoji search, NumPad, Editing pad) par exact same logic:
     * Quick tap: 1 character delete.
     * 400ms se zyada hold: Fast continuous deletion (50ms interval).
     * Extended continuous hold: Automatically full WORD-BY-WORD deletion me switch ho jata hai with active "WORD" badge.

7. Character Key Long-Press Alternate Popups:
   - Har key par secondary symbol mapped hai (jaise 'A' par '@', 'S' par '#').
   - Long press (>240ms) karne par floating bubble aati hai jisme base key aur secondary symbol dono aate hain. User swipe karke select kar sakta hai.

8. Spacebar Cursor Control:
   - Spacebar par left/right ungli swipe karne se text cursor fluidly move hota hai, text ke beech exact point par navigate karna super easy ho jata hai.


--------------------------------------------------------------------------------
CATEGORY 2: UI/UX & MATERIAL 3 VISUAL POLISH
--------------------------------------------------------------------------------

9. Anti-AI-Slop Modern Geometry & Tactility:
   - Alphabet keys ko modern 10.dp corner radius aur Spacebar/Enter ko 12.dp rounded pills me design kiya gaya hai.
   - Hairline 0.5.dp border outlines aur soft elevation drop-shadows jo real hardware mechanical keyboard jaisi tactile depth deti hain bina cluttered lage.
   - Key press karne par Gboard-style floating magnifier bubble aati hai.

10. Professional Theme System & AMOLED Dark Mode:
    - Light Theme: Google Pixel / Material You inspired soft off-white canvas (0xFFF1F3F5), pure white keys (0xFFFFFFFF), aur Google Blue accent (0xFF1A73E8).
    - Dark Theme: High-contrast AMOLED-ready dark charcoal (0xFF1A1C1E) with elevated key surfaces (0xFF282A2D) aur pastel blue accent (0xFF8AB4F8).
    - Preset Accents: Deep Navy, Nordic Forest, Royal Purple, Crimson Red.
    - Custom Theme Studio: Gallery se koi bhi photo lagao, brightness, blur, key opacity aur custom font colors adjust karo.

11. Zero-Flicker Window Height Stability:
    - Fixed total height locking: totalKeyboardHeight = standardKeyboardContentHeight + 40.dp.
    - Isse Android ka InputMethodManagerService bar-bar window re-measure nahi karta, aur tools switch karte waqt 1 second ka black screen / close-reopen blink permanently khatam ho gaya hai.

12. Physical / System Back Button Navigation:
    - Android service level pe KEYCODE_BACK intercept kiya gaya hai.
    - Agar user Emoji, Clipboard, Translate ya kisi bhi sub-screen pe hai, toh phone ka back button keyboard close nahi karega, balki seedha LETTERS view par return karega.
